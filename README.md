Flutter UI Assignment

This project is a simple Flutter application demonstrating basic user interface components as part of an assignment. It includes a welcome screen, a styled container, an image loaded from the internet, an interactive button, and a basic login layout.

Features
1. Title Bar

A title bar is displayed at the top of the app using the AppBar widget.

2. Welcome Message

A centered welcome message is shown inside a styled Container with padding, border radius, and background color.

3. Interactive Button

An ElevatedButton is included that prints a message to the console when clicked.

4. Image from the Internet

An Image widget loads an image from a URL to demonstrate the use of network images.

5. Login Layout

A simple login section is built using Column and Row widgets.
It includes:

Username TextField

Password TextField

Login and Register buttons placed side by side

Requirements

To run this project, ensure that you have:

Flutter SDK installed

An emulator or physical device connected

A code editor such as VS Code or Android Studio

How to Run

Clone the repository:

git clone <your-repository-link>


Navigate to the project directory:

cd your-project-folder


Run the application:

flutter run

Project Purpose

This project demonstrates the fundamentals of Flutter UI design, widget layout, styling, and user interaction. It serves as an introductory exercise for learning Flutter.
